# Session Checkpoint
> Fill this when ending a session mid-task. Load on next session start.

## Current branch (what I'm working on)
One line. The active task, not the project.

## Committed (decisions made this session)
Locked choices — architecture, naming, scope cuts. Reversing these costs real effort.

## Open branches (questions / alternative approaches still live)
What's unresolved. Each item is a fork that could still go either way.

## Next entry point (the first file/command to open next time)
The exact file path or command that restores working context immediately.
